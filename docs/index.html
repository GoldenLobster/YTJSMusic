🎵 YTJSMusic Documentation

A native iOS music streaming application powered by YouTube.js inside JavaScriptCore with Apple Music catalog discovery, zero-network cache playback, and real-time karaoke lyrics.

iOS 15.0+ Swift 5.9 YouTube.js v10.0.0 LRCLIB MIT License

🌟 What Makes YTJSMusic Unique?

🔍

Apple Music Catalog Discovery

Browse millions of songs, albums, and discographies with live debounced search suggestions without an Apple Music subscription.

⚡

Instant Zero-Network Playback

Cached tracks bypass YouTube network resolution completely, initiating audio rendering locally in under 20ms.

🎤

Karaoke Synced Lyrics

Live scrolling time-coded lyrics with smooth highlight animations, tap-to-seek, and instrumental break indicators.

🚀

Isolated JavaScriptCore Runtime

Runs YouTube.js in pure ECMAScript with 11 custom Web API polyfills backed by native Swift URLSession & CryptoKit.

💡 No WebViews or External Servers Required

YTJSMusic does not use WKWebView wrappers or intermediary proxy backend servers. Stream resolution, signature deciphering, and caching happen natively on the iOS device.

🚀 Quick Start Guide

Set up your local development environment and run YTJSMusic on your iOS simulator or physical device.

Prerequisites

  • macOS Sonoma / Sequoia with Xcode 15.0+
  • Node.js 18+ & npm
  • iOS 15.0+ device or Simulator

1. Clone and Install Dependencies

BASH
# Clone repo
git clone https://github.com/GoldenLobster/YTJSMusic.git
cd YTJSMusic

# Install Node dependencies
npm install

2. Build Runtime Bundle

BASH
# Bundle YouTube.js for JavaScriptCore using esbuild
npm run bundle

3. Run Desktop Test Simulation

BASH
# Verify music search and stream resolution on desktop
node test_music.js

4. Open in Xcode & Run

Open YTJSMusic.xcodeproj in Xcode, choose the YTJSMusic target and your device/simulator, and press Cmd + R.

🔍 Apple Music Catalog Search & Discovery

Subscription-free access to Apple Music's metadata, rich discographies, and artist releases.

Features

  • Live Search Suggestions: Populates autocomplete queries dynamically with a 300ms debounce.
  • Filter Chips: Seamlessly filter results across Top Results, Songs, Albums, and Artists.
  • Album Discography View: Displays high-res album art, release year, track counts, explicit badges, and one-tap Play All or Shuffle Play.
  • Artist View: Detailed artist biography header with genres and complete release discography.
  • Fresh Tab Reset: Tapping "Cancel" completely clears the query, suggestions, and results container.

⚡ Intelligent Song Matching Engine

How YTJSMusic bridges Apple Music metadata to YouTube Music audio streams.

Matching Workflow

  1. User selects an Apple Music track (Title, Artist, Album, Duration).
  2. SongResolverCacheManager checks the local SQLite/memory resolution index. If cached, returns the video ID in <1ms.
  3. On cache miss, dispatches an InnerTube query via JSCYoutubeClient.
  4. Calculates confidence score based on:
    • Duration Delta Filter: Rejects candidates differing by >15 seconds (filtering out live bootlegs and video skits).
    • Levenshtein Normalized Distance: Fuzzy matches song title and artist strings.
  5. Stores the winning video ID in the persistent cache for instant future lookup.

🎤 Karaoke Synchronized Lyrics

Real-time time-coded lyrics with interactive seeking powered by LRCLIB.

Capabilities

  • Karaoke Dynamic Highlighting: The active lyric line smoothly enlarges and highlights in lockstep with the playback position.
  • Centered Auto-Scroll: Keeps the current lyric centered in view via ScrollViewReader.
  • Tap-to-Seek: Tap any past or upcoming lyric line to immediately jump playback to that timestamp.
  • Instrumental Break Cues: Gaps >8 seconds between lyrics display an animated 🎵 ... indicator.
  • Plain Lyrics Fallback: Seamless fallback to static formatted lyrics when time-codes are unavailable.

📋 Queue & Local Playlists

Full playback queue management and offline playlist creation.

Queue Features

  • Drag-and-Drop Reordering: Adjust upcoming song order dynamically.
  • Swipe-to-Delete: Remove tracks from upcoming playback.
  • Play Next / Append Queue: Context menu actions on any track across search, albums, and the now-playing screen.

Local Playlists

  • Create custom playlists stored on device.
  • Add tracks from Search, Album Views, or Now Playing 3-dots action menu.
  • Full Shuffle Play support with automatic queue construction.

Components

🚀 3-Tier Cache & Cache Bypass

Sub-20ms instant local playback via zero-network cache bypass.

3-Tier Cache Breakdown

  • Tier 1: In-Memory Manifest Index (AudioStreamCacheIndex): Synchronous, lock-protected lookup under 0.1ms.
  • Tier 2: Coalesced Disk Reader (AudioStreamCacheDiskReader): Dedicated serial queue reader for instant local streaming.
  • Tier 3: Asynchronous Persistence (AudioStreamCacheManager): Background chunk persistence.

📡 Stream Resource Loader

YTStreamResourceLoader: Intercepting AVPlayer requests with ytaudio://.

Key Capabilities

  • Range Header Enforcement: Enforces mandatory byte range headers for YouTube CDN (rqh=1).
  • 256KB Adaptive Chunking: Avoids CDN anti-bulk-download throttling.
  • Automatic 403 Renewal: Automatically re-resolves stream signatures if URL tokens expire mid-song.
  • UTI Mapping: Injects com.apple.m4a-audio for native hardware acceleration.

⏱️ Duration-Based Prefetcher

Dynamic two-level prefetching for true gapless playback transitions.

Prefetch Thresholds

  • Tracks < 3 min: Prefetches 20 seconds before end.
  • Tracks 3–8 min: Prefetches 30 seconds before end.
  • Tracks > 8 min: Prefetches 45 seconds before end.

Prefetches both song resolution metadata and the initial 512KB audio buffer for upcoming queue items.
